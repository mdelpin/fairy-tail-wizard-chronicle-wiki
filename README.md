# Wizard Chronicles Wiki

Unofficial game-data reference built with Quartz 5.

Public site: https://mdelpin.github.io/wizard-chronicles-wiki/

The `content` directory contains filtered character kits, lacrimas, effect applications, and portraits. Personal account records and raw Capacities exports are not included. The source data is maintained in Capacities and regenerated by the separate private importer.

## Local preview

```sh
npm ci
npx quartz plugin install --from-config
npx quartz build --serve
```

Open http://localhost:8080/. Pushes to `v5` publish through GitHub Actions.

## Coverage

104 UR characters and 115 lacrimas in the current catalog. Non-UR coverage is incomplete. Four portraits and some new-effect details are unavailable. Larcade's signature is explicitly unconfirmed. Values and source text may contain localization or transcription errors; this wiki does not claim verified strategy rankings.
