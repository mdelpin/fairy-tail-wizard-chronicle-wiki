## Coverage

The current export covers the supplied UR catalog. N, R, and SR coverage is not yet complete. Missing images will be added as they become available.

This reference contains game data, without development priorities or strategy rankings.

## Reading the data

Skill text is an endgame reference where supplied. Normal Lv.3 unlocks at 7★, Special Lv.3 at 9★, and Ultimate Lv.3 at 11★. Unknown values are left unspecified. Localization and transcription errors may remain; source text is provided for comparison.
